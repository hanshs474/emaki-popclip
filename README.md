# emaki for PopClip

Official [PopClip](https://www.popclip.app/) extension for emaki (emaki.ai), the Japanese-language AI video generator for Seedance 2.5 and Seedance 2.0: select text, click **emaki**, get a [Seedance 2.5](https://emaki.ai/seedance-2-5) clip of it.

Source for the extension is in `Emaki.popclipext/`; its readme says what is sent. To start from a picture instead of text, use [image to video](https://emaki.ai/image-to-video) on [emaki](https://emaki.ai/?utm_source=github&utm_medium=popclip).

日本語での使い方は [シーダンス](https://emaki.ai/) へ。
