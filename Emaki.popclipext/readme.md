# emaki

Select any text, click **emaki**, and the text becomes a [Seedance 2.5](https://emaki.ai/seedance-2-5) video clip that opens in your browser when it is ready (a clip takes a few minutes).

## What it sends

The selected text is sent to the [emaki](https://emaki.ai/?utm_source=popclip&utm_medium=extension) API as the prompt, with your API key. Nothing else is sent.

## Setup

Create an API key at [emaki.ai/settings/apikeys](https://emaki.ai/settings/apikeys) and paste it into the extension's settings. Each run costs credits on your emaki account, the same price as on the website. The Model setting switches between Seedance 2.5, [Seedance 2.0](https://emaki.ai/seedance-2), Seedance 2.0 mini and a still image.

日本語での使い方は [シーダンス](https://emaki.ai/) へ。
